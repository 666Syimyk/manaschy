# UI assets

В релизе сохранены только две иллюстрации, которые непосредственно отображаются на онбординге. Запись проекта, существовавшая до релизной проверки, определяет их как созданные специально для Manaschy; внешняя страница-источник отсутствует. Точный генератор и исходный prompt в репозитории не сохранились. Дата ниже — известная дата изменения исходного файла, а не независимо подтверждённая дата создания.

| Файл | Размер | Источник / известная дата | Основание использования | Активный экран |
|---|---:|---|---|---|
| `hero-light-wide.png` | 1536×1024 | Проектная иллюстрация Manaschy; файл датирован 2026-06-22 | Предоставлена в рабочем проекте как оригинальный фон продукта; внешний контент не встроен | Онбординг, desktop/tablet |
| `hero-light-mobile.png` | 864×1821 | Проектная иллюстрация Manaschy; файл датирован 2026-06-22 | То же основание | Онбординг, телефон |

SHA-256 текущих файлов:

```text
hero-light-mobile.png  A50C314BF085C6C2EA82EE115F4286FDA471B41FDA24F818C9E3CAF5AD76423C
hero-light-wide.png    877858BDD1A0DF9CB6780776692D46E2CA91F2A438E622AD15C5214B1EEC102F
```

Перед публичной публикацией правообладатель продукта должен сохранить у себя исходную запись создания/заказа этих двух файлов. Неиспользуемые иллюстрации, орнаменты, иконки и дубликаты удалены из релизных каталогов, а не получили неподтверждённое описание прав.

`npm run assets:audit` проверяет точный список из шести релизных PNG, размеры, прозрачность и отсутствие вероятного встроенного checkerboard-фона.
