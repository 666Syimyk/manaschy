# Manaschy 1.0

Manaschy — читатель «Манаса» и двуязычный справочник для Android, iOS и статического web. В «Материалах» по умолчанию открыт каталог 42 разделов четырёхтомника Сагымбая Орозбакова (2018): поиск по заголовкам, фильтр по тому, переход к странице оригинала, предыдущий/следующий раздел. При локальном web-запуске эпос отображается обычным выделяемым текстом, без встроенного PDF-просмотрщика. Локальная служба извлекает выбранную страницу источника; PDF можно отдельно открыть для сверки. Оригинал на кыргызском, без машинного перевода и пересказа. Это один вариант «Манаса», не полная трилогия.

Отдельная вкладка «Статьи» сохраняет 10 материалов на русском и кыргызском, поиск, закладки, историю и отметки «прочитано». Каталог источников содержит страницы UNESCO и ссылки на четыре тома оригинала.

Проект не требует API-ключей или аккаунта. Текстовый читатель и чат используют локальную Node-службу на `127.0.0.1:8091`, запускаемую вместе с Expo. В «Чате» можно спросить о любом моменте без выбора эпизода: поиск охватывает четыре тома, а установленная локальная Ollama (`qwen3.5:4b`) объясняет найденные фрагменты. Ответы могут ошибаться; ссылки открывают точные страницы для сверки. Облачного API, аналитики, рекламы и уведомлений нет.

## Что работает офлайн

**Статус чата: экспериментальный.** Технические тесты проходят, но проверка настоящих ответов выявила путаницу событий и ошибки перевода кыргызского оригинала. Текущую Qwen 4B нельзя считать достоверным справочником. См. [фактический отчёт](docs/LOCAL_CHAT_VERIFICATION.md); для улучшения потребуется отдельный выбор модели/сервиса.

В установленном Android/iOS-приложении весь справочный текст, интерфейс и иллюстрации входят в сборку. На устройстве под ключом `manaschy-guide-store-v1` сохраняются только:

- версия локальной схемы;
- выбранный язык и размер текста;
- факт прохождения онбординга;
- идентификаторы закладок;
- даты открытия и завершения материалов;
- идентификатор последнего открытого материала.

Эти данные не отправляются на сервер. Для текста эпоса нужна работающая локальная служба. Она читает проверенный PDF из `tmp/epic/`, если он уже есть, иначе **требуется интернет** для загрузки с manas-discovery.kg. Источник получает обычные технические данные HTTP-запроса. Книги и извлечённый полный текст не включены в сборку; загруженные службой документы хранятся только в памяти процесса. Сохранение прогресса относится к статьям, не к страницам эпоса. Статический сайт требует сеть для первой загрузки и обычного обновления страницы; PWA-кэш и офлайн-перезагрузка web не заявлены.

## Локальный запуск

Требуются Node.js 22.13+ (для Node 24 — 24+), npm и среда, поддерживаемая Expo SDK 56.

```bash
npm ci
npm start
```

После запуска можно открыть web клавишей `w` или использовать:

```bash
npm run web
npm run android
npm run ios
```

Для чата запустите уже установленную Ollama с моделью `qwen3.5:4b`, затем `npm run web -- --port 8081` и откройте `http://localhost:8081/chat`. Приложение не устанавливает и не скачивает модели автоматически. При первом открытии строится временный индекс 2 149 страниц; можно заранее набрать вопрос. Переписка хранится только в памяти до перезагрузки приложения, индекс — до остановки службы. Генерация на CPU может занимать несколько минут; есть кнопка остановки. Подробности и ограничения: [проверка локального чата](docs/LOCAL_CHAT_VERIFICATION.md).

`npm start` и `npm run web` запускают и Expo, и текстовый читатель. Если Expo уже запущен отдельно, используйте `npm run reader:start`. По умолчанию разрешены локальные web-адреса на портах 8081–8089. Служба доступна только на этом компьютере, не является публичным API и не разворачивается командой статического экспорта. На телефоне и публичном сайте локальный текстовый режим не работает без отдельного разрешённого сервиса и настройки `EXPO_PUBLIC_READER_URL`; внешняя ссылка на PDF остаётся доступна. Подробнее: [docs/EPIC_READER.md](docs/EPIC_READER.md).

Для собственного development client установлен совместимый `expo-dev-client`. Облачная сборка потребует входа в аккаунт Expo и собственных подписывающих данных издателя:

```bash
npx eas-cli build --platform android --profile development
```

### Движок JavaScript в Expo SDK 56

Нативные профили используют legacy Hermes: в `app.json` согласованы `useHermesV1: false` и сборка React Native из исходников, в `package.json` закреплён совместимый `hermes-compiler`, а `babel.config.js` включает профиль `hermes-v0`. Это обход известной для SDK 56 регрессии памяти Hermes V1 при наличии Worklets/Reanimated. Эти три настройки нужно обновлять только вместе; их согласованность защищена release-тестом. Нативная сборка из-за этого дольше, зато Android и iOS production-бандлы компилируются в Hermes bytecode.

## Проверки

Полная локальная проверка исходников:

```bash
npm run check
```

Она последовательно запускает ESLint, строгий TypeScript, Jest, Node-тесты локального читателя, проверку двуязычного контента и источников, интроспекцию разрешений Expo и аудит шести релизных PNG.

Проверка статического web-экспорта:

```bash
npm run export:web
npm run export:verify
```

Проверка production-бандлов платформ:

```bash
npx expo-doctor
npx expo export --platform android --output-dir dist-android
npx expo export --platform ios --output-dir dist-ios
```

Экспорт JavaScript и ассетов не заменяет сборку подписанного APK/AAB/IPA. Полный порядок публикации, проверка нативных манифестов и внешние шаги издателя перечислены в [docs/RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md).

## Структура

- `src/app` — Expo Router: шесть вкладок, страницы материалов, источников, приватности и методологии.
- `src/features/chat` — локальный чат с RU/KY, отменой и ссылками на страницы.
- `src/data/guides` — реестр из 10 материалов, тем и восьми link-only источников.
- `src/data/epic` — заголовки и страницы разделов четырёхтомника, без стихотворного корпуса.
- `src/features/episodes` — каталог и постраничный текстовый читатель.
- `scripts/reader` — локальный HTTP-сервис, проверка PDF и восстановление порядка строк и колонок.
- `src/features` — поиск, чтение, сохранённое, настройки и безопасное локальное состояние.
- `src/services/external-links.ts` — проверка опубликованного HTTPS-источника перед открытием.
- `scripts/content` — структурная проверка материалов и ссылок.
- `scripts/release` — проверка разрешений и полноты статического экспорта.
- `assets` — только используемые релизные изображения с описанием происхождения.

## Контент и права

Тексты материалов написаны для приложения и сопровождаются ссылками на факты. В приложение не копируются тексты, сканы, изображения или медиа UNESCO: записи источников имеют область прав `link_only`. Файлы DOCX в корне — редакционные исследовательские материалы и не попадают в runtime.

PDF четырёхтомника доступны на сайте источника, но открытая лицензия на их повторную публикацию не установлена. Поэтому приложение хранит только библиографию, заголовки и страницы, а не копию книг. Разделы следуют заголовкам издания; в первых томах деление редкое. Если новый раздел начинается посреди страницы, одна страница входит в диапазоны обоих соседних разделов. Подробности: [docs/EPIC_READER.md](docs/EPIC_READER.md).

Структурные валидаторы подтверждают наличие переводов, ссылок и метаданных, но не заменяют редакторскую проверку фактов, качества кыргызского перевода и юридическое подтверждение издателя перед публикацией.

Идентификаторы релиза: Android `kg.manaschy.app`, iOS `kg.manaschy.app`, схема ссылок `manaschy`, версия `1.0.0`, Android `versionCode` 1, iOS `buildNumber` 1.
