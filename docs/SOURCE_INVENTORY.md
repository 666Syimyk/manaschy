# Source Inventory — Manaschy

Реестр всех источников по эпической трилогии «Манас / Семетей / Сейтек».

**Правила:**
- `rightsStatus` обновляется только после официального подтверждения правообладателя.
- Полный текст добавляется ТОЛЬКО при `rightsStatus = public_domain` или `permission_granted`.
- Bizdin.kg и аналогичные digital copies НЕ являются автоматически verified/legal источниками.
- Исполнитель умер 70+ лет назад ≠ автоматически PD — нужно подтверждение.

## Какой источник может стать первым для импорта

Наилучший кандидат — **вариант Орозбакова**:
- Исполнитель умер 96 лет назад (1930)
- Устный текст вероятно является общественным достоянием
- Рукопись в реестре ЮНЕСКО «Память мира»
- 9-томное академическое издание НАН КР

**Что нужно сделать до импорта:**
1. Обратиться в НАН КР с запросом о статусе прав на текст 9-томника
2. Уточнить: можно ли использовать сам записанный текст Орозбакова (1922–1926) без editorial apparatus?
3. При положительном ответе: получить письмо / документ о разрешении
4. Изменить `rightsStatus` с `unknown` на `public_domain` или `permission_granted`
5. Изменить `verificationStatus` на `verified`
6. Подготовить manifest с реальным оглавлением по изданию
7. Запустить `npm run content:import -- --file <manifest> --dry-run`

## Процесс обновления реестра

1. Найти источник (книга, архив, рукопись, аудиозапись).
2. Проверить организацию / издание.
3. Запросить официальное подтверждение прав использования.
4. Добавить запись в эту таблицу.
5. Добавить `EpicSource` в `src/data/epic/sources.ts`.
6. Запустить `npm run sources:validate`.
7. После подтверждения прав — изменить `rightsStatus`.
8. После экспертной проверки текста — изменить `verificationStatus` на `verified`.
