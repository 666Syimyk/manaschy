# Проверка локального чата — 29 сентября 2026

## Реализовано

Отдельная страница `/chat` без выбора эпизода. Поиск по 42 разделам и 2 149 уникальным страницам четырёхтомника Орозбакова (2018), локальная Ollama qwen3.5:4b, RU/KY, отмена, новый разговор, ссылки на точные страницы. PDF, индекс и полный текст не включены в клиентский пакет. Переписка не сохраняется постоянно.

## Подтверждённые проверки

- Индекс из уже имеющихся локальных PDF: 8,4–8,7 секунды, 2 149/2 149 страниц.
- Полный `npm run check` после исправления связности контекста: 183 Jest-теста и 39 Node-тестов, типы, lint, контент, источники, разрешения и ассеты — успех. Это не проверка достоверности модельных пересказов.
- `npm run export:web` и `npm run export:verify`: успех, проверены 68 обязательных маршрутов и 404, включая `/chat`.
- Целевой поиск в клиентском JS не обнаружил серверных модулей chat/PDF.js, имён API-ключей или контрольной строки оригинала. Значения секретов не читались. Это целевая проверка, не формальное доказательство отсутствия любых чувствительных данных.
- Chrome: визуально проверены desktop и 390×844, шесть пунктов навигации, видимые поле/кнопка и ввод. Shift+Enter не отправил вопрос; Enter отправил его (этот запрос завершился таймаутом при одновременной диагностике модели). «Новый разговор» очистил вопрос и ошибку. После перебоев управления соединение восстановлено, временный viewport сброшен. Полный браузерный сценарий «успешный ответ → ссылка → назад» не подтверждён; его части покрыты автоматическими тестами.
- Автотесты покрывают отмену/поздний ответ, возврат к переписке, неверные ссылки и page-параметры, Enter/Shift+Enter/IME, ошибки сервиса и источников, лимиты, Host/Origin и приватность.

## Обнаруженные ограничения модели

Ollama сообщает CPU-only (size_vram=0). При шести фрагментах были ответы за 127–145 секунд и таймаут 180 секунд. Контекст уменьшен до трёх фрагментов / 4 500 символов; весь четырёхтомник остаётся в поиске. Это уменьшает доступный контекст одного объяснения.

Первые настоящие проверки выявили ответ на неправильном языке, неточный вывод и пропуски известного эпизода из-за кыргызских окончаний и неудачных поисковых подсказок. Подсказки сокращены, добавлены короткие префиксы, покрытие запроса, близость слов и заголовки. Ошибка обработки пустого `not_found` исправлена: теперь показывается локализованное отсутствие подтверждения, а не ошибка формата. Анахроничный вопрос о ракете на Марс получил `not_found`.

Независимая проверка кода выявила одну существенную проблему: модель объединяла разные сцены с валидными ссылками. Подбор исправлен на один лучший фрагмент и его непосредственных соседей в том же разделе; регрессионный тест прошёл RED→GREEN. Однако повторная настоящая проверка через HTTP всё ещё НЕ ПРОЙДЕНА по фактическому качеству:

Завершающая серия окончена. Обнаруженные проблемы нельзя исправить одной проверкой URL: она гарантирует допустимость страницы, а не истинность пересказа. Экспериментальный статус и предупреждение об ошибках показаны в UI над перепиской. Для следующего этапа пользователь должен выбрать более сильную локальную модель либо явно разрешить облачный сервис. Ни модель, ни облачный API автоматически не менялись. Требование достоверно отвечать о произвольном моменте остаётся невыполненным; это явный блокер приёмки, а не пройденная проверка.

## Решения и рабочая копия

Изменения оставлены в текущем каталоге на ветке `feature/local-epic-chat`, чтобы не потерять прежние незакоммиченные изменения читателя. В коммиты включены только собственные новые файлы и последующие изменения в них; смешанные файлы оставлены незакоммиченными. Поэтому одни коммиты новой ветки не воспроизводят весь текущий проект без сохранения прежней работы владельца.

Итоговый read-only review запущен параллельно последним CPU-проверкам, но его вывод не заменял проверку фактов. Связность контекста исправлена и покрыта тестом; фактическое качество модели после этого всё ещё не прошло приёмку. Рабочий журнал сохранён для продолжения, ветка не слита и не опубликована.

## Запуск

Работающая Ollama с установленной qwen3.5:4b, затем `npm run web -- --port 8081`; открыть `http://localhost:8081/chat`. Новые модели автоматически не скачиваются. Интернет нужен для PDF только если их нет локально. Публичный сайт и телефон потребуют отдельного решения по сервису и правам.
