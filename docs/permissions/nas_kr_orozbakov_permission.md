## Следующие шаги

1. **Получить письменный документ** от НАН КР, подтверждающий разрешение.
2. Сохранить скан/копию в этой папке: `docs/permissions/nas_kr_orozbakov_permission_signed.pdf`
3. Обновить `sources.ts`:
   ```ts
   verificationStatus: 'verified',
   verifiedBy: '<ФИО эксперта, проверившего документ>',
   verifiedAt: '<дата получения письменного документа>',
   ```
4. Обновить `permissions.ts` — добавить `contactPerson` и актуализировать `grantedAt`.
5. Запустить `npm run permissions:validate && npm run sources:validate`.
6. После verified: подготовить manifest с реальным текстом первой книги.
