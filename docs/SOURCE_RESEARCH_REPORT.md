## 2. Источники по циклу «Манас»

### 2.1 Вариант Сагымбая Орозбакова (ПРИОРИТЕТ №1)

**Источник:** `src-nas-kr-orozbakov-placeholder`

- **Издание:** Эпос «Манас». Академическое издание. В 9-ти книгах / ред. С. Мусаев. — Бишкек: НАН КР, «Туран», 1995–2014.
- **Объём:** 183 000 строк.
- **Запись текста:** 1922–1926 гг. (первая организованная запись эпоса на территории Кыргызстана).
- **Манасчи:** Сагымбай Орозбаков (1867–1930).
- **UNESCO:** Рукопись включена в реестр «Память мира» в 2023 году.
- **Правовой статус:** Исполнитель умер 96 лет назад → устный текст вероятно является общественным достоянием. НО: редакционный аппарат НАН КР (1995–2014) имеет отдельное авторское право. Нужно разграничить «устный текст Орозбакова» и «editorial work НАН КР».
- **Что нужно:** Официальный запрос в НАН КР.
- **Доступность:** Bizdin.kg предоставляет цифровые копии некоторых томов.

### 2.2 Вариант Саякбая Каралаева

**Источник:** `src-nas-kr-karalaev-placeholder`

- **Издание:** Манас. Семетей. Сейтек: эпос. В 4-х томах. — Бишкек: «Туран», 2014. — 500 553 строки.
- **Запись:** 1935–1937 (первоначальная), полный сбор 1936–1952.
- **Манасчи:** Саякбай Каралаев (1894–1971). «Гомер XX века».
- **Правовой статус:** НЕ общественное достояние — ожидать до 2041 года.
- **Что нужно:** Разрешение НАН КР или наследников Каралаева.

### 2.3 Вариант Жусупа Мамая

**Источник:** `src-nas-kr-mamay-placeholder`

- **Описание:** 8-частный вариант — единственный в истории полный исполненный вариант эпоса целиком. ~230 000 строк.
- **Манасчи:** Жусуп Мамай (1918–2014). Синьцзянский кыргыз (КНР).
- **Правовой статус:** НЕ общественное достояние — ожидать до 2084 года.
- **Переводы:** Китайский, русский, английский, турецкий, японский, казахский, уйгурский.
- **Что нужно:** Установить правообладателей (китайские издательства и/или наследники).

### 2.4 Вариант Шаабая Азизова

**Источник:** `src-academy-azizov-manas`

- **Объём:** 8 368 строк «Манаса» + «Эр Сарык» (~2 000) + «Куланарык» (1 842).
- **Манасчи:** Шаабай Азизов (1927–2001). Ач-Суу, Иссык-Кульская обл.
- **Хранение:** Институт языка и литературы им. Ч. Айтматова, НАН КР.
- **Правовой статус:** НЕ общественное достояние — ожидать до 2071 года.
- **Что нужно:** Запрос в ИЯЛ Айтматова или наследникам.

### 2.5 Вариант Каба Атабекова

**Источник:** `src-aitmatov-inst-atabekov-mss`

- **Объём:** 28 181 строка (тетради 3–5: 1997–2000).
- **Особенность:** Рукописи написаны самим исполнителем (формат А4).
- **Манасчи:** Каба Атабеков (р. 1926). Торт-Кул, Тонский р-н.
- **Хранение:** Фонд рукописей ИЯЛ им. Ч. Айтматова.
- **Правовой статус:** Зависит от даты смерти исполнителя — требует уточнения.
- **Что нужно:** Установить жив/умер. Запрос в ИЯЛ Айтматова.

### 2.6 Советское академическое издание (1958–1960)

**Источник:** `src-aitmatov-inst-sov-manas-1958`

- **Издание:** Манас: кыргызский героический эпос. В 4-х томах. — Фрунзе: ИЯЛ АН Кыр. ССР, 1958–1960.
- **Правовой статус:** Требует уточнения — советское издание, составители могут иметь отдельные права.
- **Что нужно:** Проверка у НАН КР как правопреемника.

## 12. Что нужно сделать человеку вручную

### Шаг 1 — Контакт с НАН КР (наивысший приоритет)

```
Национальная академия наук Кыргызской Республики
Сайт: https://naskr.kg/en/
```

Написать официальное письмо о:
1. Правовом статусе текста Орозбакова (1922–1926 запись, умер 1930)
2. Условиях использования 9-томного издания (1995–2014)
3. Возможности получить оглавление первого тома для структурирования эпизодов

### Шаг 2 — Проверка на Bizdin.kg

Открыть https://new.bizdin.kg и найти издание Орозбакова:
- Убедиться в соответствии библиографических данных
- Не использовать текст до получения ответа от НАН КР

### Шаг 3 — Обновление sources.ts после ответа

После получения письменного подтверждения прав:
```ts
// В src/data/epic/sources.ts обновить:
id: 'src-nas-kr-orozbakov-placeholder',
rightsStatus: 'public_domain',        // если PD подтверждён
verificationStatus: 'verified',       // только после экспертной проверки текста
verifiedBy: '<имя эксперта>',
verifiedAt: '<дата>',
```

### Шаг 4 — Подготовка manifest

После подтверждения прав и получения оглавления:
```bash
cp data/manifests/drafts/manas-sagymbay-orozbakov-draft.json \
   data/manifests/manas-orozbakov-vol1.json
# Заполнить реальным текстом первой главы
npm run content:import -- --file data/manifests/manas-orozbakov-vol1.json --dry-run
```

### Шаг 5 — Контакт с ИЯЛ им. Айтматова

```
Институт языка и литературы им. Ч. Айтматова НАН КР
```

Запросить:
1. Статус прав архивных материалов Азизова и Атабекова
2. Уточнить дату смерти К. Атабекова
