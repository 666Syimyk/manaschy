# Оригинал «Манаса»: читатель четырёхтомника

## Реализованный объём

Каталог использует кыргызский текст варианта Сагымбая Орозбакова в четырёхтомном издании «Классикалык изилдөөлөр жана тексттер» (Бишкек: Принт-экспресс, 2018). Это не объединение вариантов и не вся трилогия «Манас — Семетей — Сейтек».

Источник PDF — manas-discovery.kg, каталог `/wp-content/uploads/2021/07/`, файлы `С.ОРОЗБАКОВ_1-TOM_на-печать.pdf` — `С.ОРОЗБАКОВ_4-TOM_на-печать.pdf`. Файлы проверены 28 сентября 2026 года. Количество страниц: 552, 544, 560, 516.

## Навигация

Заголовки и номера страниц берутся из самого издания, не генерируются ИИ. Каталог содержит 42 раздела: 2 / 2 / 7 / 31 по томам. Редкое деление первых томов сохраняется. Диапазоны соседних разделов могут пересекаться одной страницей, если заголовок расположен после окончания предыдущего текста. Номер страницы PDF совпадает с печатным номером в просмотренных томах. Выбор эпизода открывает его первую страницу; доступны предыдущая/следующая страница и ввод номера в пределах раздела.

Основной читатель показывает обычные выделяемые текстовые блоки: заголовки, прозу и стихи с переносами строк. Встроенного PDF, iframe и панели браузерного PDF-просмотра нет. Текст извлекается автоматически PDF.js из исходного документа, а не генерируется ИИ. В двухколоночных фрагментах сначала читается левая колонка, затем правая. На общей странице текст обрезается по заголовку выбранного раздела. Автоматическое извлечение может сохранить ошибки символов и переносов самого PDF; кнопка оригинала предназначена для сверки.

## Локальная служба чтения

`npm start` / `npm run web` запускают Expo и `scripts/reader/server.mjs`. При отдельно запущенном Expo достаточно `npm run reader:start`. Служба слушает только `127.0.0.1:8091`, разрешает локальные web-origin на портах 8081–8089 и обслуживает только известные идентификаторы разделов и их диапазоны страниц. Произвольные URL и пути не принимаются.

При наличии исследовательского PDF в `tmp/epic/orozbakov-2018-vN.pdf` используется он; иначе загружается фиксированный HTTPS-источник каталога. До разбора проверяются размер, SHA-256 и число страниц. Документ хранится в памяти; служба не записывает извлечённые стихи или скачанные книги на диск. Ответ содержит только запрошенную страницу. Изменившийся источник, неподтверждённая граница раздела или сетевая ошибка дают сообщение с повторной попыткой, а не выдуманный текст.

Клиент на localhost автоматически обращается к локальной службе. `EXPO_PUBLIC_READER_URL` позволяет явно задать адрес отдельно подготовленного сервиса; сам по себе этот параметр не делает loopback-сервис доступным телефону. Статический экспорт не включает Node-службу. Текстовое чтение на телефоне или публичном сайте требует отдельного решения по размещению и правам; текущая реализация рассчитана на личный локальный web-запуск. Внешний PDF по-прежнему открывается стандартным обработчиком ссылки.

## Доступ и права

Локальный реестр содержит метаданные, но не полный стихотворный корпус. В PDF 2018 года указаны © Института языка и литературы и © Принт-экспресс. Явная открытая лицензия на перепубликацию не обнаружена. Смерть сказителя в 1930 году сама по себе недостаточна для утверждения о правовом статусе всей современной редакции: нужно учитывать дату первой публикации, редакторские материалы и применимость исключения для фольклора.

Правовой статус повторного использования не заявляется как установленный. Для будущего офлайн-корпуса требуется отдельная проверка конкретного текста или разрешение правообладателя; удаление предисловия само по себе не доказывает свободу всего издания.

## Сеть и приватность

Браузер запрашивает выбранную страницу у локальной службы. Если исходного PDF нет на компьютере, служба делает обычный запрос к manas-discovery.kg, который получает технические данные, включая IP-адрес. История чтения и закладки не передаются. Внешние OCR-сервисы и облачные модели ИИ не используются. Локальный чат отправляет вопрос, последние сообщения и найденные фрагменты установленной Ollama на этом же компьютере. PDF не включён в пакет приложения; автономность без службы, сохранение позиции эпоса и публичная перепубликация книг не заявлены.

## Проверка

`npm run check` проверяет типы, тесты каталогов/маршрутов/читателя, безопасность локального HTTP-сервиса, порядок колонок, источники и сборочные ограничения. `npm run export:web` и `npm run export:verify` проверяют выпуск статических оболочек всех эпизодов, не присутствие книг в сборке. Нативное приложение следует отдельно проверить на целевых устройствах.

Отдельная страница `/chat` ищет по 2 149 уникальным страницам всех четырёх томов. Индекс и фрагменты хранятся в памяти, не в клиентской сборке; модель `qwen3.5:4b` вызывается только через локальную Ollama. Выбирать эпизод перед вопросом не нужно. Ссылка `/episode/<id>?page=N` открывает цитируемую страницу, сохраняя диалог при возврате. Это локальный исследовательский режим, не публичная перепубликация корпуса. См. [архитектуру чата](AI_API_PLAN.md) и [результаты проверки](LOCAL_CHAT_VERIFICATION.md).
