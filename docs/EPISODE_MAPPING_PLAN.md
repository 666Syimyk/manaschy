# Episode Mapping Plan — Manaschy

> Исторический план. Текущее внедрение — каталог разделов четырёхтомника Орозбакова 2018 года с чтением PDF на сайте источника: [EPIC_READER.md](EPIC_READER.md). Ниже приведены предварительные исследовательские гипотезы, а не подтверждение public domain или разрешение на импорт. Указанные здесь placeholder-маршруты теперь перенаправляют в каталог.

## Общий принцип

**Не выдумывать порядок эпизодов.**

Точное деление на эпизоды и их порядок берётся ТОЛЬКО из конкретного издания / оглавления источника.

Если оглавления нет — оставить задачу для ручной разметки экспертом.

---

## Структура данных эпизода

```ts
{
  id: string;              // 'manas-karalaev-001'
  cycleId: EpicCycleId;    // 'manas' | 'semetey' | 'seytek'
  variantId: string;       // 'manas-sayakbay-karalaev'
  order: number;           // порядок по оглавлению источника
  title: string;           // название главы/части по изданию
  shortDescription: string;
  text: string;            // ТОЛЬКО после подтверждения прав
  sourceIds: string[];     // ссылки на верифицированные источники
  sourceStatus: SourceStatus;
  rightsStatus: ContentRightsStatus;
  language: ContentLanguage;
}
```

## Соглашения по ID эпизодов

Формат: `{cycleId}-{variantShortCode}-{paddedOrder}`

```
manas-orozbakov-001
manas-orozbakov-002
manas-karalaev-001
semetey-karalaev-001
seytek-karalaev-001
```

Не использовать: `k-1`, `ep1`, `chapter_1`, `глава1` — нечитабельно.

---

## Важные ограничения

1. **Не смешивать варианты** — у каждого эпизода есть ровно один `variantId`.
2. **Не нумеровать произвольно** — только по изданию.
3. **Не добавлять текст** — пока `rightsStatus !== 'public_domain' | 'permission_granted'`.
4. **Не выдумывать названия глав** — только по оглавлению источника.
5. **ID k-1..k-3 и o-1..o-3 зарезервированы** в import-manifest.ts как base IDs — не использовать для новых эпизодов.
