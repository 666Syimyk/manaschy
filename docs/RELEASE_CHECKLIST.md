# Manaschy 1.0 — release checklist

Этот список отделяет то, что подтверждается репозиторием, от проверок готового нативного бинарника и действий владельца публикации. Галочка в первом разделе не означает, что приложение уже подписано или отправлено в магазин.

## 1. Проверки репозитория

- [ ] Рабочая копия содержит только ожидаемые изменения; секретов, ключей подписи и `.env*.local` нет.
- [ ] `npm ci` завершается успешно из зафиксированного `package-lock.json`.
- [ ] `npm run check` проходит полностью: lint, TypeScript, Jest, контент, источники, разрешения и ассеты.
- [ ] `npx expo-doctor` не сообщает ошибок проекта. Сетевой сбой записывается отдельно и не выдаётся за успешную проверку.
- [ ] `npm run export:web` и `npm run export:verify` проходят.
- [ ] `npx expo export --platform android --output-dir dist-android` проходит как проверка Android JS/assets bundle.
- [ ] `npx expo export --platform ios --output-dir dist-ios` проходит как проверка iOS JS/assets bundle.
- [ ] `npx expo config --type introspect --json` выполняется, а `npm run permissions:validate` подтверждает отсутствие запрещённых разрешений в CNG-интроспекции.
- [ ] `npm audit --omit=dev` просмотрен вручную. Не применять `npm audit fix --force`: для текущего SDK он предлагает несовместимый downgrade Expo Router/Expo. На 2026-09-28 в lock-файле остаётся один high advisory в сборочном `image-size` (Metro читает только доверенные локальные ассеты) и moderate advisory в транзитивных `query-string`/`uuid`; повторно проверить после совместимого патча SDK или перехода на SDK 57.
- [ ] Редактор вручную сверил каждый фактический абзац с указанным источником и обе локализации между собой.
- [ ] Владелец продукта сохранил подтверждение происхождения двух onboarding-иллюстраций из `assets/ui/README.md`.

## 2. Публикация статического web

- [ ] На хост загружено содержимое `dist`, а не сама папка-обёртка.
- [ ] Хост отдаёт сгенерированные HTML-файлы для прямых URL, включая `/guides`, `/sources`, `/privacy`, `/methodology`, каждый `/guide/<id>` и `/source/<id>`.
- [ ] Неизвестные URL направляются на сгенерированный Expo Router файл `+not-found.html` с настоящим HTTP-статусом **404**. Не применять общий SPA-rewrite на `index.html`.
- [ ] Включён HTTPS; корень и минимум один прямой URL материала проверены после чистой перезагрузки браузера.
- [ ] На ширине телефона и desktop проверены онбординг, пять разделов, чтение, источник, сброс и клавиатурный фокус.
- [ ] В описании сайта не заявлены PWA-установка или офлайн-перезагрузка web в версии 1.0.

## 3. Нативный preview и проверка бинарника

Эти шаги требуют EAS-аккаунт/учётные данные издателя либо локальную Android/iOS toolchain. Экспорт Metro не заменяет их.

- [ ] Выполнен `npx eas-cli build --platform android --profile preview`; получен устанавливаемый APK.
- [ ] В финальном AndroidManifest APK/AAB через `apkanalyzer manifest print`, `aapt dump permissions` или эквивалент проверено отсутствие SYSTEM_ALERT_WINDOW, VIBRATE, CAMERA, RECORD_AUDIO, READ_MEDIA_*, ACCESS_MEDIA_LOCATION, READ/WRITE_EXTERNAL_STORAGE, POST_NOTIFICATIONS и AD_ID.
- [ ] Создан production Android AAB профилем `production`, подписанный ключом издателя.
- [ ] Создан production iOS archive профилем `production`, подписанный Apple-командой издателя.
- [ ] В итоговом iOS `Info.plist` отсутствуют `NSCameraUsageDescription`, `NSMicrophoneUsageDescription`, `NSPhotoLibraryUsageDescription`, `NSPhotoLibraryAddUsageDescription` и `NSUserTrackingUsageDescription`.
- [ ] На реальном Android или iOS проверены: первый холодный запуск без сети, RU/KY, все пять разделов, поиск, чтение, закладка, завершение, перезапуск с сохранением состояния, сброс и понятная ошибка внешней ссылки без сети.
- [ ] После включения сети внешняя ссылка открывает ровно опубликованную HTTPS-страницу источника.

## 4. Действия владельца публикации

- [ ] В `app.json` добавлены реальные Expo `owner` и EAS `projectId` только после создания проекта владельцем; фиктивные значения не используются.
- [ ] Настроены и защищены Android keystore и Apple signing credentials; файлы ключей не добавлены в Git.
- [ ] Подтверждены уникальность идентификатора `kg.manaschy.app` и право на имя/иконографику продукта.
- [ ] Указаны юридическое имя издателя, support URL, публичный privacy URL и контактный email.
- [ ] Подготовлены реальные store screenshots для поддерживаемых размеров устройств, описание и локализованные метаданные RU/KY.
- [ ] Заполнены анкеты privacy/data safety в соответствии с фактическим поведением: локальная история чтения, отсутствие аккаунта, аналитики, рекламы, уведомлений и сбора данных приложением; внешние сайты имеют собственные политики.
- [ ] Приняты договоры магазинов, назначены цены/страны, пройдены возрастные и контентные анкеты.
- [ ] Загружены подписанные AAB/IPA, пройден внутренний трек/TestFlight и только затем выполнена отправка на ревью.

## 5. Версионирование следующего релиза

- [ ] Для каждой новой публичной версии обновлены `expo.version`, `android.versionCode` и `ios.buildNumber`.
- [ ] После изменения native-зависимости или `app.json` пересобран development client и оба production-бинарника.
- [ ] После изменения реестра материалов повторно выполнены контентные тесты и `npm run export:verify`.
